# 账号试用与支付宝收款

`BILLING_ENABLED=true` 启用账号级权限规则。系统管理员永久免费；普通账号从开始试用时起可使用 3 天，支付 ¥5,000 后开通一年。新账号在注册时开始试用；策略上线前已有的账号在启用后首次登录时开始 3 天试用。

系统管理员可在「用户管理」为指定普通账号授予永久免试用授权。该授权只豁免费用，不改变账号的系统权限或公司角色；授予和撤销均写入审计日志。已授予永久授权的账号不产生试用到期日或续费要求。

收款使用 ¥5,000 的支付宝收款码。收款码是私有业务资料，不随源代码提交；部署人员须通过受控私有渠道单独提供 `apps/web/public/alipay-collection.jpg`。文件缺失时，支付页面会提示联系系统管理员确认收款方式。用户扫码付款并在备注填写注册邮箱。个人收款码不提供可靠的订单回调，因此付款不会自动解锁。管理员需在「用户管理」核实支付宝账单后，点击对应账号的「确认到账开通一年」。操作会记录到审计日志，并更新该账号的权益期限。更改价格时须同步替换收款码。

生产环境在 `/opt/contrlio/.env.production` 设置：

```dotenv
BILLING_ENABLED=true
ALIPAY_RECEIVER_ACCOUNT=在受控环境中配置的收款账号
```

不要把支付宝登录密码写入系统配置。此收款码方案不需要支付宝商户私钥或 API 密钥。
